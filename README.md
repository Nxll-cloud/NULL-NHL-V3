# Null’s Playbook V4.2

Streamlit mobile-first NHL dashboard. Automatically analyzes the full selected-date slate and three previous seasons of opponent history. Open-page refresh every 30 minutes. The Odds screen compares user-imported real sportsbook CSV prices; no live sportsbook feed is bundled.

## Deploy
Upload all extracted project files to the existing GitHub repository main branch. Streamlit Cloud will install `requirements.txt` and launch `app.py`. Keep the browser tab open for periodic refresh; it is not a background scheduler.

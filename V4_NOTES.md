# Null’s Playbook V4.0 — hybrid UI
- Responsive navy/cyan premium Streamlit styling and renamed product.
- Existing NHL ranking, historical analysis, numerology, and backtesting retained.
- Player portrait cards using NHL image CDN (may be unavailable for some players).
- Exact-market sportsbook CSV comparison with no fabricated live prices or EV.
- CSV schema: player,team,market,selection,sportsbook,american_odds,updated_at; optional event_id,line.
- Live sportsbook API integration is NOT included: requires licensed provider and API credentials. Only uploaded sportsbooks can be compared.
- NBA/NFL/etc. are NOT live data modules.

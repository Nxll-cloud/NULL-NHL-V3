# V3.5 auto-enrichment

After **Rank Entire Slate**, press **Fetch NHL player biographies and arenas**. Defaults to top 50; larger runs make more NHL API calls. Source: NHL `/v1/player/{id}/landing` and schedule venue. Historical team/jersey accuracy and lineup status are **not** established by these current profiles.

Injuries, former-team storylines, revenge games, and milestones are not automatically claimed without a dedicated sourced and date-aware verification pipeline. Optional sourced storyline CSV remains available.

Exploratory numerology and gematria never modify evidence-based rankings.

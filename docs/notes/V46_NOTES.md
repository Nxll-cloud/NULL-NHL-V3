- Premium mobile-first player price cards, matching player portraits where NHL model IDs are available.
- Exact-market multi-book comparison and biggest discrepancy sorting by decimal payout improvement.
- Model-backed sorting and longshot filter (+300 or longer); these are descriptive, not calibrated EV.

- Data-source configuration moved out of the default interface; API keys remain in Streamlit Secrets.

- V4.4 snapshot workflow and V4.5 odds API / CSV fallback retained.
